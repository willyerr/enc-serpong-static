# Every Nation Serpong Church — Static Website

A responsive static website built with plain HTML, CSS, and JavaScript.

## Run locally

You can open `index.html` directly in a browser. For a local server, open a terminal in this folder and run:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000

## Notes
- The supplied church logo is in `assets/logo.png`.
- Stock photography and Google Fonts are loaded from the internet.
- The sermon area uses YouTube's search embed for Every Nation Church sermons; the displayed video results may change over time.
- The Sunday service time and location follow the supplied wireframe and should be confirmed before publishing.
- Event names and descriptions are sample placeholder content.
